# Промпт 64: документный сплит, протокол до запуска

1000 размеченных пар, `joined_reference`; все 301 пары старого test включены как обычные пары. Отдельный тест на них не проводится. Зафиксирован `spanver/splits1000.json`; старый `spanver/splits.json` не меняется. Состав и обе контрольные суммы проверяются до каждого задания. `gold_sha256` — SHA-256 канонического JSONL из полного gold без старого поля split, способ сериализации указан в файле сплита.

## Разрешённое уточнение по размеру обучения

Заказчик выбрал сохранение схемы 52. Каждый внешний фолд ~100 пар, следующий по циклу внутренний ~100. Градиентное обучение идёт на оставшихся ~800, а не на 900: внутренний фолд используется и для ранней остановки (до 15 эпох), и для выбора порога. Точные размеры сохраняются в отчётах. Нельзя говорить о приросте +270 тренировочных пар или о 900 обучающих парах. Переобучение на 900 не проводится.

## Неизменённая схема и оценка

Используются `train46.train_variant(..., "v2", permanent_freeze=True)`, признаки/энкодер `spanver.lexfeat`, пять сидов 0–4, прежний декодер `nested_cv35.predict`, прежняя сетка `train52_chunks.GRID` и точное правило `train52_chunks`: максимальный token F1 на внутреннем фолде при **обоих** ограничениях FPR token и pair ≤ 0,40, одинаковые значения разрешаются в порядке сетки. Два ограничения не следует заменять одним, если цель — оставить схему неизменной. Повторного выбора по внешним фолдам нет.

Pooled считается по всем 1000 внешним парам (один прогноз на пару); вместе с ним — `folds_over_fpr`, максимум FPR и разброс по фолдам. Token метрика и all-positive baseline через covered_tokens. CI — bootstrap пар 10000 раз, seed 64; из-за общей принадлежности документов следует учитывать зависимость пар. Span F1 IoU ≥ 0,5 и точный выводятся отдельно; pair F1 соответствует штатной оценке с IoU 0,5. Скорость измеряется внутри первого фолда на одной обученной модели (сид 0), на паре, наиболее близкой к медиане длины документа всего набора, 5 повторов после прогрева, 4 потока; результат — внутреннее сравнение на этом раннере.

Критерии договора — pooled token F1 ≥ 0,50 и pooled token FPR ≤ 0,40 одновременно; скорость — дополнительная строка с фактическим измерением. Старый и новый наборы, внутренние фолды и выбор порогов различаются; сравнение не является парным экспериментом. Раздельный вклад увеличения обучающей выборки и снятия заражения этим прогоном не устанавливается, дополнительные контрольные прогоны для этого в этом задании не назначаются. Линия 63, её конфигурации и файлы не используются.
