# RAGTruth (English source)

Источник: github.com/ParticleMedia/RAGTruth, лицензия MIT.
Файлы: response.jsonl (17790 ответов, из 7664 со спанами, 14289 спанов), source_info.jsonl (исходные документы).
Формат JSONL. Поля спанов: start, end, text, label_type, meta. end НЕ включается.
Длина спанов: медиана 32 знака, максимум 1441.
Типы: Evident Conflict 5324, Evident Baseless Info 6237, Subtle Baseless Info 2527, Subtle Conflict 201.

Используется как источник разметки для перевода на русский. Разметка сделана людьми, 2-3 аннотатора на пример.
