# RAGTruth-ru: русская версия RAGTruth со span-разметкой

## Что это

Машинный перевод датасета RAGTruth (MIT) на русский с сохранением разметки
границ фрагментов. Источник разметки — ручная аннотация RAGTruth (2–3
аннотатора на пример). Перевод выполнен методом двухъязычной замены:
ответ режется по спанам на куски, каждый кусок переводится отдельно,
затем куски склеиваются в том же порядке. Координаты спанов получаются
точными по построению — выравнивание не используется.

## Схема записи

```json
{
  "pair_id": "rtru-8798",
  "doc_id": "c3ec998eb12f3655",
  "document_text": "переведённый исходный документ",
  "model_output": "переведённый ответ модели",
  "spans": [{"start": 120, "end": 246, "type": "Evident Baseless Info"}],
  "label_type": "Evident Baseless Info",
  "source": "ragtruth_ru",
  "task_type": "Summary",
  "model": "gpt-4-0613"
}
```

**Координаты:** `start`, `end` — в символах, `end` ВКЛЮЧИТЕЛЬНЫЙ
(в отличие от исходного RAGTruth, где `end` не включается).
Проверка: `model_output[start:end+1]` даёт текст спана.

## Ограничения, о которых надо знать

1. **Перевод машинный, не выверенный человеком.** Разметка границ перенесена
   из оригинальной ручной аннотации, но сам текст — машинный перевод.
   Ошибки перевода возможны.
2. **Домен другой.** RAGTruth собран на английских новостях (CNN/DM),
   диалогах, Data2txt и QA. Наши документы — русские научные и
   энциклопедические тексты. Домен надо адаптировать дообучением на
   RusHallu-RAG.
3. **Стиль разметки промежуточный.** Медиана 41 знак против наших 145.
   Лучше, чем RuFacts (2 знака), но не идентично.
4. **Метрики на этом наборе нельзя смешивать с метриками на RusHallu-RAG.**
   Это отдельный источник, оценивать отдельно и указывать, на каком
   наборе получена цифра.
5. **Не все 17 790 ответов переведены.** Взято 6000 с 1–2 спанами +
   1500 негативов. Остальные 11 790 (с 3+ спанами) не переводились —
   их можно добрать тем же скриптом при необходимости.
