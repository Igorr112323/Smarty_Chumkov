# Промпт 47: В2 и пять сидов

Результаты — адаптивная вложенная CV на 699 train/val парах, уже использованных в экспериментах; это не независимая отложенная часть 1200 пар. Пороги выбирались только по четырём внутренним фолдам, оба FPR ≤0,40 на каждом; по внешним меткам пороги не выбирались. Сохранён клаузный `expand`, предложенческий снап, компенсация и EMA отключены. Замена двух сидов на пять не гарантирует прирост +0,0238: это наблюдение для другого контроля, а не причинная оценка В2.

В4 относительно В2: Δ macro token F1 **+0,0226**. Это наблюдаемая разница двух и пяти сидов, не гарантия переноса на другую выборку.

Проверка первых двух сидов В4 относительно В2: совпадение числа эпох 40/40, лучшей эпохи 40/40; максимум абсолютного расхождения train/inner loss 0.0043585797. Версии torch и transformers совпали соответственно 40/40 и 40/40. Loss расходится, побайтовая идентичность моделей и чисто причинное объяснение разницы не доказаны.

## Правило остановки

В4: macro token F1 0,5014, сводный token F1 0,4999, сводный FPR_token 0,3697. По macro-метрике 0,50 преодолён, поэтому В5 не запускался; по сводному F1 значение 0,50 не достигнуто даже на этих 699 парах. Это различие нельзя скрывать округлением или считать подтверждением договора.

## Ограничения и веса

Сводные F1/FPR рассчитаны по объединённым out-of-fold прогнозам; средний FPR и максимальный по фолдам отдельно показаны выше. Договорная оценка на единой отложенной по документам части 1200 пар не проводилась, выполнение договора не подтверждено. Выбор вариантов и правило остановки адаптивны по уже исследованным внешним фолдам. Test 301, extra и внешние данные не использовались; архитектура encoder не менялась.

В каждом завершённом пятисидовом варианте сохранены 25 основных checkpoint — 5 сидов каждого из 5 внешних ансамблей; восстановление каждого и равенство его вероятностей проверены в Actions. Это не веса всех 100 внутренних обучений; сетки выбора, истории и предсказания сохранены в `artifacts/ablation47_*`. Инструкции по инференсу и происхождение сохранённой модели — в манифестах. Пять моделей одного фолда не подтверждают средние показатели всех пяти фолдов.
