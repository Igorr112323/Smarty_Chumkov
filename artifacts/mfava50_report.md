## Протокол

Вариант 1: отдельный label-free MLM-TAPT для каждого из пяти сидов, одна эпоха по всем 267 references и generated_text, блоки до 256 токенов, маскирование 15%, AdamW lr 1e-5, batch 4. Повторяющиеся записи не дедуплицировались. Затем вложенная CV по протоколу В5: до 15 эпох, patience 3, пять сидов, embeddings постоянно заморожены на supervised этапе; порог выбран только по внутренним фолдам при FPR_token и FPR_pair ≤0,40. Клаузный expand сохранён; предложенческий снап и компенсация отключены.

Test 301 не оценивался, silver_annotations не использовались; другие новые внешние наборы не подключались. Вход V1 — внешний mFAVA без меток, а исходные 699 — прежний train/val. Новых независимых оценок нет; метрики, основанные на предварительно изученных фолдах, не подтверждают договор.
