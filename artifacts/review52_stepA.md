## Вердикт по шагу A

Правка **принята как исправление дефекта** (обучение и инференс теперь видят
одинаковый контекст), но **как улучшение качества — отклонена**:

- знак эффекта нестабилен: фолд 1 **−0.0735**, фолд 2 +0.0186;
- средний token F1 0.51584 при CI [0.398985; 0.617448] — неотличим от 51
  (0.5273 на 5 фолдах) и от all-positive 0.5001320461281141;
- **AUC почти не вырос**: 0.6538 → 0.6584, то есть на 0.005, при цели
  «≥ 0.68» из критерия шага C;
- span-уровень на фолде 2 вырос заметно (0.1860 → 0.2316 бьётся с 0.31068 по
  pooled-метрике), но на фолде 1 стоит на месте (0.2083 → 0.2128).

## Что это означает для шага C

Критерий шага C — `AUC ≥ 0.68` **или** `token F1 > 0.5074 при FPR ≤ 0.40`.
По итогу шага A:
- AUC 0.6584 < 0.68 — не выполнено;
- token F1 0.51584 > 0.5074 — формально выполнено, но CI [0.398985; 0.617448]
  накрывает и 0.5001, и 0.5074, а на одном из двух фолдов результат **хуже** 51.

Для шага C нужен рост AUC до 0.68, а шаг A дал +0.005. Авторазметка при этом
заблокирована пилотом (см. `artifacts/review52_stepB.md`): разметчик совпадает
с обучаемой моделью, поэтому добавить AUC ей нечем.
