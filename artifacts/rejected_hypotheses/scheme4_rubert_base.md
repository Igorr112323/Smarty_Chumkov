# Схема 4: rubert-base-cased закрыта

Схема отклонена по решению куратора по результатам прогона и диагностики; это не доказательство невозможности исправления в принципе. Полный отчёт: `artifacts/base34_report.md`.

- Замер модели составил 908,03 / 464,60 / 425,09 / 122,82 мс на 1000 символов при длинах 200 / 1000 / 5000 / 20000 знаков соответственно, против цели 30 мс. Документы длиной 20000 получены повторением; оценка int8 ×2–3 не измерена.
- Fold 1: нулевые метрики и отсутствие предсказанных спанов; из 171 сочетания порогов 126 отвечали ограничениям FPR, но ни одно не дало ненулевой token F1. Fold 2: token F1 0,2517, span F1 0,1087. Двухфолдовый прогон не засчитывается как валидная CV.
- Гипотеза замороженного энкодера опровергнута для проверенных финальных весов: в оптимизаторе 177 858 818 параметров, в обоих фолдах относительно исходной модели изменились все 192 тензора 12 слоёв энкодера. Сравнения эпох 1 и 3 нет.
- Малый набор данных как причина разброса — гипотеза, не установленная экспериментом. Внешние данные, test 301, ONNX и int8 при диагностике не запускались.
