# Диагностика 39: без обучения и нового инференса

Источник метрик — `artifacts/nested38_summary.json`, пять внешних фолдов на 699 train+val. Смешанные исходные CSV поточно читались целиком; записи test пропускались по ID до извлечения ответа и разбора разметки, test не оценивался. Локальные изменения до синхронизации ветки сохранены в `stash@{0}`.

## 1. Pair gate и token

**Token precision / recall / F1 считаются после gate:** `tools/nested_cv35.py:50–55` возвращает пустые спаны при максимальной вероятности субтокена < 0,45; строки 58–64 передают именно эти предсказания в `metrics`; `spanver/evaluate.py:79–101` считает токены по ним. Средние после gate: **0,4517 / 0,4529 / 0,4506**. До gate метрики в отчёте не сохранены.

Gate — порог максимума токенных вероятностей, а не отдельная обучаемая pair-головка. Pair TP требует совпадения хотя бы одного спана с gold по IoU ≥ 0,5 (`spanver/evaluate.py:79–94`), тогда как token recall учитывает перекрытие токенов даже при IoU < 0,5. Кроме того, token recall взвешен числом токенов, а pair recall — числом пар. Поэтому значения не обязаны совпадать.

## 2. Метрики пар после gate

Числа TP и FP восстановлены однозначно из сохранённых FPR, F1, размеров фолдов и позитивов; P и R вычислены явно. Здесь pair P/R/F1 — **реализованная IoU-зависимая метрика**, а не обычная бинарная классификация. Все gate = 0,45; start/extend — отдельные токенные пороги.

| фолд | позитивы / негативы | TP / FP / FN | pair P / R / F1 | P / R / F1 по наличию любого выходного спана |
|---:|---:|---:|---|---|
| 1 | 44 / 96 | 9 / 13 / 35 | 0,4091 / 0,2045 / 0,2727 | 0,5667 / 0,3864 / 0,4595 |
| 2 | 47 / 91 | 12 / 8 / 35 | 0,6000 / 0,2553 / 0,3582 | 0,6923 / 0,3830 / 0,4932 |
| 3 | 49 / 92 | 6 / 18 / 43 | 0,2500 / 0,1224 / 0,1644 | 0,4545 / 0,3061 / 0,3659 |
| 4 | 56 / 85 | 13 / 8 / 43 | 0,6190 / 0,2321 / 0,3377 | 0,7037 / 0,3393 / 0,4578 |
| 5 | 43 / 96 | 9 / 12 / 34 | 0,4286 / 0,2093 / 0,2813 | 0,5385 / 0,3256 / 0,4058 |

**Важная семантика:** на положительной паре спан без совпадения IoU ≥ 0,5 даёт FN, но не FP пары; на отрицательной любой выходной спан — FP. Справа — классификация по наличию выходного спана, не количество пар, прошедших только gate. FPR_pair по фолдам: 0,1354 / 0,0879 / 0,1957 / 0,0941 / 0,1250; FPR_token: 0,2540 / 0,2283 / 0,4036 / 0,2849 / 0,2341.

## 3. Гранулярность

Проверен только разрешённый train+val: **699 пар, 239 позитивных, 300 gold-спанов**; длина **5 / 157 / 1363** знаков (мин / медиана / макс). Данные совпали по SHA-256 с `nested38_summary.json`. Число 423 в прежнем отчёте относится к нашим **1000** парам, а не доказанно к 1200; исторические 423 имеют 5 / 145 / 1363, включая ранее израсходованный test. Повторно его не анализировали.

Эвристика предложения: границы по `. ! ? …` перед пробелом и по переносу строки, без крайних пробелов; аббревиатуры могут ошибочно разделяться. Из 300: **77** строго внутри одного предложения, **110** совпадают с предложением по границам, **113** пересекают границы нескольких предложений. Это не ручная лингвистическая разметка; «пересекает несколько предложений» не обязательно означает большую длину в знаках, чем у каждого из них.

| span-метрика по 5 фолдам | F1 mean ± population std |
|---|---:|
| исходная: совпадение при IoU ≥ 0,5, не точное равенство границ | **0,2229 ± 0,0562** |
| строгая: совпадают обе границы | **не рассчитано** |
| совпадение при любом char-overlap | **не рассчитано** |

Протокол для недостающих F1: после gate, в пределах каждой пары сопоставлять спаны 1:1 в порядке предсказаний и gold, тип не учитывать; для exact совпадают обе включительные границы, для overlap достаточно ≥1 общего символа. TP — сопоставленные спаны, FP/FN — оставшиеся, F1 = 2TP/(2TP+FP+FN); затем среднее и population std по фолдам. Для числа несовпадающих перекрытий считать каждый предсказанный спан не более одного раза, если он пересекает любой gold, но не имеет ни одного точного совпадения с gold.

Это число и два F1 **не установлены**: нужны пообъектные предсказания из пяти JSON-артефактов run `43914581442`; в локальной сводке их нет, прямое скачивание завершилось EOF. Частичное перекрытие само по себе не доказывает разрыв gold на части.

Никакое расширение не выполнялось.
