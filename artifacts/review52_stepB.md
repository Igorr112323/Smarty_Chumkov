но не независимое качество; для ориентира PsiloQA (IoU 71 %) нужен именно
внешний сильный разметчик. Ниже — цифры как есть.

По букве правила (IoU 0.45…0.60) это «шаг C с весом 0.3 и половинным объёмом».
По духу правила — **стоп**: бинарный F1 0.4938 против требуемых 0.75 означает,
что авторазметчик ошибается в каждом втором решении «есть нарушение / нет».

## Почему масштабирование бессмысленно по построению

Авторазметка может добавить только ту информацию, которую разметчик уже
содержит. Разметчик — это и есть обучаемая модель. Метрики согласия выше
показывают, что в его разметке 46 % ошибок на уровне пары. Обучение на такой
разметке воспроизведёт её ошибки, а не добавит сигнала: цель шага C (AUC по
знакам 0.6538 → ≥ 0.68) требует **новой** информации, а не переупаковки старой.

Это подтверждается независимо потолком из стадии 3: оракульный порог на том же
сигнале даёт token F1 0.4791 при all-positive 0.5001320461281141.

## Что было бы нужно, чтобы шаг B имел смысл

1. Внешний сильный разметчик (LLM с промптом), недоступный в песочнице.
   Проверяется только на раннере с сетью — это отдельное решение по бюджету
   и по политике (внешние данные и внешние метки мандат разрешает, но
   договор требует не подменять человеческие метки).
2. Либо смена целевого сигнала: сейчас модель учится отличать золотые знаки
   RAGTruth (доля золота в ответе 0.2995). Возможно, AUC 0.6538 — свойство
   разметки, а не модели, но проверяется это обучением, а не авторазметкой.

## Решение

**Авторазметку не масштабирую.** Докладываю цифры и останавливаюсь, как
предписано правилом «IoU < 0.45 → стоп» с оговоркой, что формально IoU выше
0.45, но бинарный F1 в 1.52 раза ниже порога, а разметчик совпадает с
обучаемой моделью, поэтому шаг C не может дать прироста.
