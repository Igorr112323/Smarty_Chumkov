# Итоговая справка: зафиксированные результаты и незавершённый раунд 43

**Статус:** последняя запрошенная тренировка не выполнена; значения «стало» и вложенная кривая 20 вариантов снапа отсутствуют. Цель token F1 ≥ 0,50 при обоих FPR ≤ 0,40 на наблюдаемых внешних фолдах существующей baseline не достигнута. Независимого подтверждения нет.

## Определения метрик для согласования

Все показатели ниже рассчитываются **после** gate и декодирования. Gate = 0,45 — порог максимума вероятностей субтокенов, отдельной pair-головки нет. Это предлагаемые технические определения, а не решение о том, что включить в договор.

- **Token P/R/F1:** токены — последовательности непробельных символов (`\S+`) в ответе. Токен считается покрытым спаном при хотя бы одном общем символе; TP/FP/FN — пересечение и разности покрытых множеств. F1 = 2TP/(2TP+FP+FN).
- **Span exact F1:** предсказанные и gold-спаны в пределах пары сопоставляются 1:1 в их порядке, тип не учитывается. Совпадение — обе включительные границы равны. F1 = 2TP/(2TP+FP+FN).
- **Span any-overlap F1:** тот же протокол, но совпадение — хотя бы один общий символ. Это метрика спанов, **не** посимвольная F1 из `spanver/lt/evaluator.py`.
- **Span IoU≥0,5 F1:** тот же порядок 1:1, совпадение — пересечение / объединение включительных диапазонов ≥0,5. Исторический показатель 0,2229 относится к этому правилу, а не к exact.
- **Pair F1:** TP — позитивная пара с хотя бы одним совпавшим по IoU≥0,5 спаном; FN — позитивная без такого совпадения; FP — отрицательная с любым предсказанным спаном. Это совместная метрика класса и локализации: позитивная пара с ошибочными границами даёт FN, но не FP пары. P=TP/(TP+FP), R=TP/(TP+FN), F1 — их гармоническое среднее.
- **FPR_pair:** доля отрицательных пар с хотя бы одним выходным спаном. **FPR_token:** доля не покрытых gold токенов, покрытых прогнозом, среди всех не покрытых gold токенов во всех парах. Отчёт показывает среднее и максимум пяти внешних фолдов. Точность типа — доля правильных типов среди спанов, совпавших по IoU≥0,5.

Метрики вычисляются на каждом фолде, затем усредняются; не следует смешивать это со сводным micro-F1. Сравнения ниже адаптивны: те же внешние фолды уже использовались при выборе конфигураций.

## Снап и потолок при старой детекции

При фиксированных старых предсказаниях сравнение B3 на внешних фолдах дало exact F1 **0,2367** вместо **0,1398**; any-overlap почти не изменился: **0,3760** вместо **0,3715**. Это согласуется с улучшением границ, но выбор B3 по внешним результатам адаптивен. Его максимум FPR_token **0,4490**, выше 0,40. Протокол B3 и все варианты — в `artifacts/snap42_report.md`.

При сохранении числа предсказанных спанов в каждой паре и сопоставлении 1:1: **142** выходных спана, максимум **83 TP**, 300 gold; потолок exact F1 — **0,3760** как среднее пяти фолдов. Он относится только к текущей фиксированной детекции, не к новой модели после обучения. **183 gold-спана не пересекаются ни с одним текущим прогнозом**; минимум 217 gold останутся несопоставленными при идеальной правке границ и неизменных парах/числе выходов.

Более сильное ограничение для промпта 43: в наружном фолде 3 старый FPR_token = **1493/3699 = 0,4036226**. B3 только расширяет или объединяет спаны, не сокращая множество покрытых токенов, поэтому при неизменных старых прогнозах никакая комбинация порога пересечения и разрыва B3 не снизит этот внешний FPR до 0,40. Это не утверждение о допустимости комбинаций на внутренних фолдах и не результат новой тренировки. Подсчёт — `artifacts/fpr43_feasibility.json`.

## Почему раунд 43 не завершён

Проверены все **20** исходных JSON-артефактов run `43914581442`: в них есть сводные `inner_grid`, но нет пообъектных внутренних вероятностей/спанов; пообъектные внешние `outer_predictions` есть в пяти. Аудит — `artifacts/inner43_audit.json`, run `43938445784`. Имеющиеся пять `predictions_fold*.jsonl` — **внешние**. Использовать их вместо внутренних для выбора 20 настроек нарушило бы требуемый вложенный протокол: модели других внешних фолдов могли обучаться на целевом внешнем фолде.

Поэтому честно построить требуемую внутреннюю кривую и выбрать её победителя из сохранённых предсказаний не получилось; 15-эпоховое обучение с этим победителем не запускалось. Результатов, времени и числа эпох раунда 43 нет; изменять frozen или объявлять успех нельзя. Для вложенной оценки нужны ранее сохранённые внутренние пообъектные кэши либо согласование иной последовательности: при новом обучении сохранять внутренние предсказания, выбирать параметры только на них и затем оценивать внешние фолды. Ограничение на внутренние FPR само по себе не гарантирует внешний FPR ≤0,40.

Test 301 ранее израсходован на другой конфигурации и повторно не оценивался; с CV его не сравнивают. Значение **0,5138** получено в прежней CV с **2994 внешними RuFacts-негативами** и не является парным сравнением с нынешней CV без внешних данных. Extra 200, внешние данные, test 301 и новый инференс в этой работе не использовались.
