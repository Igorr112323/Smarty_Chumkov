Здесь использованы только 699 пар train/val, разбиение по связным компонентам всех doc_id; test 301 не использовался. Для каждого полного фолда модель заново загружена из checkpoint ступени A, оптимизатор запущен с нуля, выполнены 3 эпохи по всем парам остальных фолдов. Пять лексических признаков сохранены. Encoder LR 0,000004, head LR 0,0001 — в пять раз ниже ступени A. Ограничение по памяти: один fold-модель в процессе; промежуточные результаты записываются после каждого фолда.

BCE использует прежний weighted BCE pos_weight=11 без pair loss; focal использует focal gamma=2 и дополнительный pair loss с весом 0,3. Это различающиеся режимы обучения, а не контролируемое сравнение только предобучения. Прежние базовые CV также отличались составом обучения и фолдами; точные значения не являются парным сравнением.

В каждом отложенном фолде на нём же выбирается гистерезис: максимум token F1 при обоих FPR ≤ 0,40, иначе максимум без ограничений. Сетка: start 0,25…0,95 с шагом 0,10, extend 0,10…0,90 с шагом 0,10, только extend < start; pair gate 0,45, snap expand. Затем метрики измеряются на том же фолде: эти оценки оптимистичны для выбора порога, не независимы.
