# Веса абляции 46

Для каждого завершённого варианта сохраняются два сида каждого из пяти **основных внешних ансамблей**: `weights/ablation46/<вариант>/fold<N>/seed_<S>`. Это 10 checkpoint на вариант, а не все 40 моделей внутренних подборов. Веса внутренних моделей не сохраняются; их результаты выбора порога и истории обучения находятся в `artifacts/ablation46_<вариант>_outer*_inner*.json`. Перед сохранением проверяется восстановление каждого основного checkpoint и идентичность его вероятностей на соответствующем внешнем фолде. Части не больше 80 МиБ; SHA-256 и порог в манифестах.

Модель каждого фолда обучена только на его обучающих трёх фолдах. Пять таких ансамблей нельзя считать одной отдельно проверенной моделью на новой выборке. Клаузный expand сохранён, предложенческий снап отключён.

Работать из корня репозитория; Python 3.10 или новее. Файл `ваши_пары.jsonl` должен содержать непустые `model_output`, уникальные `pair_id` и `document_text`. Test 301 не использовать.
