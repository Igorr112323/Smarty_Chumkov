# rubert-base-cased — вспомогательные файлы

Эти файлы НЕ содержат весов. Веса (681 МБ) скачивает сам GitHub Actions
на раннере: там есть доступ к huggingface.co, в отличие от песочницы исполнителя.

## Что здесь

| файл | назначение |
|---|---|
| `config.json` | конфиг BERT с num_labels=2 и архитектурой BertForTokenClassification |
| `tokenizer_config.json` | исправленный конфиг токенизатора (исходный содержал только do_lower_case, из-за чего fast-токенизатор не собирался) |
| `special_tokens_map.json` | стандартный набор спецтокенов |
| `vocab.txt` | словарь, 119 547 токенов |

Положить в репозиторий: `weights/rubert-base-cased/curadoria/`

Скачивание весов делает workflow: `scripts/download_rubert_base.py`
